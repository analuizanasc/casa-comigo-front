Barra de distribuição/carga — trilho de papel afundado com preenchimento texturizado (hachura de buril). Mostra quanto cada morador carrega.

```jsx
<ProgressBar value={54} tone="barro" />
<ProgressBar value={45} tone="verde" target={50} />
```

Props: `value` (0–100), `tone` (barro/verde/indigo/ocre), `target` (linha de alvo), `height`.
