Campo de texto do Casa Comigo — rótulo em caixa-alta, foco terracota com anel macio.

```jsx
<Input id="email" label="E-mail" type="email" placeholder="seu@email.com" />
<Input id="nome" label="Nome da casa" error="Campo obrigatório" />
<Input id="cod" label="Código" hint="6 caracteres" />
```

Props: `label`, `error`, `hint` + todos os atributos nativos de `<input>`.
